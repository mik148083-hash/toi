АДИЛЕТ & АКБЕРМЕТ — БАШТАПКЫ ЧАКЫРУУ САЙТЫ

Бул топтом сиз жиберген чакыруу.html файлынын негизинде даярдалды. Баштапкы HTML түзүлүшү, каймак түстүү конверт дизайны, анимациялар жана чакыруу мазмуну сакталды. Ири музыка маалыматтары өзүнчө assets/music.mp3 файлына чыгарылды.

Файлдар:
- index.html — сайттын башкы барагы (GitHub Pages үчүн)
- styles.css — баштапкы стилдер
- script.js — баштапкы интерактивдүү функциялар
- config.js — музыка жөндөөлөрү
- thanks.html — кошумча рахмат барагы
- assets/music.mp3 — баштапкы файлдын ичиндеги аудио

GitHub'га жүктөө:
1. ZIP архивди телефондо чыгарыңыз.
2. Ичиндеги index.html, styles.css, script.js, config.js, thanks.html файлдарын репозиторийдин эң башкы папкасына жүктөңүз.
3. assets папкасын ичиндеги music.mp3 файлы менен кошо жүктөңүз. Папканын аты так assets болсун.
4. Commit changes басыңыз.
5. Settings > Pages бөлүмүндө Branch = main, Folder = /(root) болсун.

Эскертүү: Google Fonts жана Tailwind CSS CDN аркылуу жүктөлөт, ошондуктан сайтты ачканда интернет керек. Музыка браузердин autoplay чектөөсүнө жараша колдонуучу конвертти ачканда ойнойт.
