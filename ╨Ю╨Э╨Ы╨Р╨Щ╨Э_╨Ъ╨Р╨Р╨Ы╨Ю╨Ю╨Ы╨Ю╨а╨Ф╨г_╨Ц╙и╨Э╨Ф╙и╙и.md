# Адилет & Акбермет — жаңыртылган чакыруу сайты

## Өзгөртүүлөр
- Шоу-программа жана бий: 19:00 — 22:00.
- Коноктордун каалоо-тилектерин бардык түзмөктөрдөн бирдей көрүү үчүн Supabase онлайн базасына туташтыруу даярдалды.

## Жалпы онлайн каалоо-тилектерин иштетүү
1. https://supabase.com сайтына кирип, акысыз Project түзүңүз.
2. Project → SQL Editor → New query бөлүмүнө төмөнкү SQL-ди көчүрүп, Run басыңыз:

```sql
create table if not exists public.guest_wishes (
  id bigint generated by default as identity primary key,
  name text not null,
  status text not null,
  wish text not null,
  created_at timestamptz not null default now()
);
alter table public.guest_wishes enable row level security;
create policy "Anyone can read guest wishes" on public.guest_wishes
  for select to anon using (true);
create policy "Anyone can add guest wishes" on public.guest_wishes
  for insert to anon with check (true);
 grant select, insert on public.guest_wishes to anon;
 grant usage, select on sequence public.guest_wishes_id_seq to anon;
```

3. Project Settings → API бөлүмүнөн Project URL жана anon/public key маанилерин алыңыз. **service_role key колдонбоңуз жана эч кимге жөнөтпөңүз.**
4. `index.html` файлын редакциялап, `SUPABASE_URL` жана `SUPABASE_ANON_KEY` деген эки бош мааниге тиешелүү маанилерди киргизиңиз.
5. Өзгөртүлгөн `index.html` файлын GitHub репозиторийиндеги эски файлдын үстүнө жүктөп, Commit changes басыңыз.
6. GitHub Pages жаңырган соң коноктор жазган каалоолор жалпы онлайн базага сакталат жана баарына көрүнөт.

Эскертүү: URL жана anon key кошулмайынча, форма мурдагыдай эле ошол түзмөктө гана сактайт. Бул файл азырынча интернетке автоматтык жарыяланган жок.
